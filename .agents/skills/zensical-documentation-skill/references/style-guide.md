# Documentation style guide

## Voice and tone

Write directly to the reader using "you". Prefer active voice, present tense, concrete verbs, and short paragraphs. Be calm and precise in errors and troubleshooting. Avoid marketing claims in technical procedures.

## Headings

Use one H1 per page. Do not skip heading levels. Use sentence case. Make action headings outcome-oriented, such as "Configure single sign-on".

## Procedures

State the outcome first. List prerequisites before steps. Use numbered lists for sequences and bullets for unordered choices. Put one primary action in each step. Follow commands with a verification signal.

## Code and commands

Use fenced blocks with a language identifier. Keep examples minimal, runnable, and safe. Use placeholders such as `<api-token>` and explain each placeholder. Never include real credentials. Distinguish shell input from output. Include expected output only when stable.

## Links

Use descriptive link text. Link to `.md` source paths with relative URLs. Avoid "click here" and raw URLs in prose. Check fragments and filename casing.

## Images and diagrams

Every informative image needs concise alt text. Do not put essential instructions only in an image. Provide diagram source when maintainable. Crop screenshots to the relevant area and avoid exposing personal or secret data.

## Tables

Use tables for compact comparisons or structured reference data, not long prose or multi-step instructions. Ensure tables remain readable on narrow screens.

## Terminology

Maintain one term for each concept. Expand unfamiliar acronyms on first use. Use UI labels exactly as rendered. Maintain a glossary for domain terms.

## Localization

Avoid idioms and culture-specific humor. Keep sentences concise. Do not concatenate fragments in examples intended for translation. Mark code, variables, and product names clearly.

## Front matter

Use metadata only when supported by the project. Useful fields may include title, description, status, owners, review date, and version scope. Verify syntax against the installed Zensical version.
