# Python Production Engineer Skill

Skill em portugues para agentes que criam e revisam Python production-ready, inspirado em praticas publicas de engenharia do Google e da AWS.

## Instalacao

Copie a pasta `python-production-engineer` para o diretorio de skills do seu agente. O arquivo principal e `SKILL.md`.

## Conteudo

- `SKILL.md`: instrucoes operacionais do especialista.
- `references/quality-checklist.md`: gate final de qualidade.
- `references/review-severity.md`: classificacao consistente para code review.
